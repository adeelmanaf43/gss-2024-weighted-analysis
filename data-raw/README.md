# Raw data (not in Git)

The raw GSS file isn't stored in this repo. To rebuild the project:

1. Go to https://gss.norc.org/get-the-data/stata.html and download **2024** under
   "Individual Year Data Sets".
2. Unzip it into this folder, so the data file is at `data-raw/GSS2024.dta`.
3. Optional: save the 2024 GSS Codebook and "What's New in 2024" here for reference.
